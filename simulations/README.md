# Campañas de simulación

Cada campaña tendrá su propio directorio, configuración y archivo README:

- `monochromatic-neutrons/`: energías entre 1 meV y 1 keV;
- `atmospheric-neutrons/`: flujo atmosférico producido mediante ARTI;
- `fast-high-energy/`: componente rápida y de alta energía;
- `soil-albedo/`: espectro emergente de suelo seco;
- `ambe-validation/`: comparación con la fuente de \(^{241}\mathrm{AmBe}\).

No deben almacenarse aquí salidas masivas de las corridas.
